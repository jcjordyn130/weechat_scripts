# sarcasm
Adds random capitalization to the current sentence or word

Example:
- /sarcasm: this is a sentence > ThIs Is A SeNtEnCe
- /sarcasm_word: this is a word > this is a WoRD

## Configuration
None. Load script, bind /sarcasm or /sarcasm_word to a hotkey, and use it.
